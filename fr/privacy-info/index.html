Votre confidentialité dans SimpleScan PDF — questions fréquentes

Date de mise à jour : 2026-08-08

Cette page répond aux questions les plus fréquentes sur les données et la confidentialité dans SimpleScan PDF. Vous trouverez les informations juridiques complètes dans la Politique de confidentialité.

Mes documents sont-ils envoyés à un serveur ?

Non. Tous les fichiers PDF, Word, Excel, PowerPoint, TXT et les images que vous consultez ou traitez dans l'Application restent exclusivement sur votre appareil. L'Application ne copie, n'envoie ni ne partage leur contenu avec aucun serveur — ni les nôtres, ni ceux de tiers.

L'Application exige-t-elle un compte ou une connexion ?

Non. SimpleScan PDF fonctionne sans compte. Pas de connexion, pas d'inscription, pas de synchronisation avec le cloud.

La numérisation avec l'appareil photo envoie-t-elle les photos à Google ?

Non. La numérisation utilise la bibliothèque Google ML Kit Document Scanner, mais l'ensemble du traitement (détection des bords, correction de perspective, recadrage) s'effectue entièrement sur votre appareil — hors ligne. Les images numérisées ne quittent pas le téléphone.

Que collectez-vous exactement ?

L'Application utilise Firebase Analytics et Firebase Crashlytics, qui collectent :

  • des événements d'utilisation de base (ouverture de l'app, ouverture d'un document — uniquement le type de fichier, par exemple « pdf », sans nom ni contenu),
  • le nombre de documents trouvés lors de la numérisation de dossiers (uniquement le nombre, pas les noms),
  • des données techniques de l'appareil (modèle, version d'Android, version de l'Application),
  • des rapports de plantage (stack trace en cas de plantage de l'Application).

Nous ne collectons pas : les noms de fichiers, les chemins, le contenu des documents, les contacts, la localisation GPS, l'historique du navigateur.

L'Application affiche-t-elle des publicités ?

Pendant les 90 premiers jours après l'installation — non. Durant cette période, aucune requête publicitaire n'est envoyée.

Après 90 jours, peuvent apparaître :

  • une bannière en bas de l'écran de la liste des documents,
  • une publicité plein écran après la fermeture du cinquième document consécutif.

Les publicités n'apparaissent jamais pendant la lecture d'un document.

Comment désactiver les publicités personnalisées ?

Si vous vous trouvez dans l'Espace économique européen, lors du premier affichage d'une publicité, l'Application vous demandera votre consentement via le formulaire Google UMP. Vous pouvez refuser — les publicités seront alors affichées sans personnalisation.

Pour modifier la décision ultérieurement :

Paramètres → Options de confidentialité des publicités

(l'option n'apparaît que pour les utilisateurs des régions où le consentement est requis).

Comment réinitialiser mon Advertising ID ?

Paramètres Android → Confidentialité → Publicités → Réinitialiser l'identifiant publicitaire

Vous pouvez aussi désactiver totalement la personnalisation des publicités au même endroit.

Comment supprimer toutes mes données de l'Application ?

Trois moyens :

  1. Effacer l'historique local : Paramètres dans l'Application → Effacer l'historique.
  2. Effacer les données de l'Application : Paramètres Android → Applications → SimpleScan PDF → Stockage → Effacer les données.
  3. Désinstaller l'Application : cela supprime l'ensemble des métadonnées et paramètres locaux.

Mes documents seront-ils supprimés si j'efface les données ?

Vos fichiers d'origine sur l'appareil (par exemple dans le dossier Téléchargements) NE seront PAS supprimés. L'Application ne conserve que les métadonnées (noms, chemins, paramètres) dans sa base — ce sont elles qui seront effacées. Les fichiers demeurent.

Font exception les documents créés directement dans l'Application (numérisations, PDF édités) — ces derniers sont enregistrés dans le dossier système Documents/SimpleScan PDF/ et y restent jusqu'à ce que vous les supprimiez vous-même.

Mes fichiers sont-ils chiffrés ?

La base de métadonnées locales se trouve dans le répertoire privé de l'Application, inaccessible aux autres applications de votre appareil (isolation par le bac à sable Android).

L'Application elle-même ne chiffre pas le contenu des fichiers PDF, mais propose l'outil « Protéger le PDF par mot de passe » (Outils → Protéger le PDF) qui permet d'appliquer un mot de passe AES à un fichier choisi.

L'Application est-elle sûre pour les enfants ?

L'Application ne s'adresse pas aux enfants de moins de 13 ans et ne collecte pas sciemment leurs données.

Pourquoi l'Application demande-t-elle l'accès à tous les fichiers ?

Afin de pouvoir trouver et afficher automatiquement tous vos documents PDF/Word/Excel/TXT situés dans les différents dossiers de l'appareil. Sans cette autorisation, vous ne verrez que les documents que vous ouvrez manuellement.

L'Application se contente de lire les métadonnées de ces fichiers pour les afficher dans la liste — elle ne copie, ne modifie ni n'envoie leur contenu.

Vous pouvez refuser cette autorisation ou la retirer dans les paramètres d'Android — l'Application continuera à fonctionner, mais avec une vue limitée des fichiers.
