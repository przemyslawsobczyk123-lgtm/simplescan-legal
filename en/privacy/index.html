2. Scope and purpose of the Application

SimpleScan PDF is a local document manager that runs on the user's device. It allows you to:

  • browse and organise PDF, Word, Excel, PowerPoint, TXT, CSV files and JPG/PNG images stored on the device,
  • open and preview those documents,
  • scan documents with the camera (edge detection and export to PDF),
  • perform basic editing of PDF files (compression, merging, splitting, rotation, adding text, password, signature, conversions).

The Application does not require a user account and does not send the content of user documents to any server.

3. What data is processed

3.1 User documents and files

  • File content remains exclusively on the device.
  • The Application reads files in order to display their content and enable operations chosen by the user (e.g. export, compression).
  • The Application does not copy, send, or share file contents with third parties.

3.2 Local document metadata (SQLite database)

The Application stores the following metadata locally in a database on the device, in order to provide manager features:

  • file name, path, and URI identifier,
  • file type, extension, MIME type, size in bytes,
  • modification date, creation date, last opened date,
  • last viewed page number (for PDF),
  • flags: "favourites", "trash",
  • user settings (theme, display name, scan quality, installation date).

The database is located in the Application's private directory and is never sent outside the device. It can be removed by clearing the Application's data or by uninstalling.

3.3 Document scanning (Google ML Kit)

The scanning feature uses the Google ML Kit Document Scanner library. Edge detection, deskewing, and image processing take place entirely on the device — scan images are not sent to Google servers or any other servers.

3.4 Firebase Analytics

The Application uses Google Firebase Analytics to measure usage and improve features. The following events are sent:

Event When What it contains
app_open opening the Application Firebase system event
document_opened opening a document only file type (e.g. pdf, docx) — no name, path, or content
scan_completed finishing a folder scan number of files found — no names or content
premium_purchased Premium purchase (currently inactive) no additional parameters

Along with these events, Firebase may collect technical device data: model, Android version, Application version, language, approximate location based on IP (country/region), pseudonymous app instance identifier.

The Application does not log document contents, file names, paths, entered text, or contact details.

3.5 Firebase Crashlytics

The Application uses Firebase Crashlytics to report crashes. At the moment of a crash, the following are sent:

  • error stack trace,
  • device model and system version,
  • Application version,
  • technical state (e.g. whether the device was online),
  • pseudonymous Crashlytics installation identifier.

No personal data, document content, or other user data is sent.

3.6 Ads (Google Mobile Ads / AdMob)

The Application displays ads provided by Google Mobile Ads (AdMob):

  • For the first 90 days after installation, ads are completely disabled — in accordance with the Application configuration (AdConfig.freeDaysWithoutAds = 90). During that period, no ad requests are sent.
  • After 90 days the Application may display:
    • a banner at the bottom of the documents list screen,
    • an occasional full-screen (interstitial) ad after closing the fifth document in a row.
  • Ads are never displayed while reading a document.

Google Mobile Ads may collect:

  • the device Advertising ID (an identifier that can be reset by the user in Android Settings),
  • IP address and approximate location (country/region),
  • information about interactions with the ad (impression, click),
  • technical device data.

More information about data collected by Google in connection with ads: policies.google.com/technologies/ads.

3.7 Ad consent in the EEA (UMP)

For users in the European Economic Area, the United Kingdom, and Switzerland, the Application uses the Google User Messaging Platform (UMP) to collect consent for ad personalisation in accordance with the GDPR. The consent form appears before the first ad is displayed.

The user may change or withdraw their ad choices at any time in:

Settings → Ad privacy options

(the option is shown only to users in regions covered by the GDPR).

4. Android system permissions

Permission Why
MANAGE_EXTERNAL_STORAGE Enables automatic search for documents in various folders of the device storage. The Application only reads file metadata to display them in the interface.
CAMERA Scanning documents with the camera.
INTERNET Firebase Analytics/Crashlytics and AdMob ads (after 90 days). The Application does not send user files over the internet.

All permissions can be revoked in the Android system Settings. Denying the file permission means the Application will only show documents opened manually.

9. User rights

Under the GDPR, every user has the right to:

  • access to their data,
  • rectification,
  • erasure ("right to be forgotten"),
  • restriction of processing,
  • data portability,
  • object to processing (including advertising profiling),
  • withdraw consent at any time (this does not affect the lawfulness of processing prior to withdrawal),
  • lodge a complaint with a supervisory authority (in Poland: Prezes Urzędu Ochrony Danych Osobowych, ul. Stawki 2, 00-193 Warszawa; you may also contact the supervisory authority of your own country of residence).

How to exercise your rights in the Application:

  • Clear local history: Settings → Clear history.
  • Revoke file access: Android Settings → Apps → SimpleScan PDF → Permissions.
  • Change ad consent: Settings → Ad privacy options (available in the EEA).
  • Reset Advertising ID: Android Settings → Privacy → Ads.
  • Delete all data: uninstall the Application or clear its data in Android Settings.

For other data-related matters, please write to support@lumirai.pl — we respond within 30 days.
